MyList class
============

Using MyList
------------

    >>> MyList = __import__('1-my_list').MyList

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Testing with negative numbers and duplicates:
    >>> my_list = MyList([5, -2, 3, 5, 1])
    >>> print(my_list)
    [5, -2, 3, 5, 1]
    >>> my_list.print_sorted()
    [-2, 1, 3, 5, 5]

Testing an empty list:
    >>> empty = MyList()
    >>> print(empty)
    []
    >>> empty.print_sorted()
    []
